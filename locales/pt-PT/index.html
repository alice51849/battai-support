Como funciona o BattAI

Regras, fontes e limites claros

O BattAI usa cinco dados das API públicas do iOS: nível da bateria, estado do carregamento, baixo consumo, estado térmico de todo o dispositivo e hora. Os outros resultados são calculados com estas leituras ou adicionados por si. Cada dado mostra a fonte e os limites.

Importar dados da bateria

Escolha um ficheiro de diagnóstico do iOS. O BattAI lê os campos compatíveis e mostra a fonte.

Exportar dados

Crie um ficheiro neste dispositivo. Nada é enviado.

Compreenda a bateria ao longo do tempo

Desbloqueie mais histórico, planeamento e relatórios.

Privacidade

Sem anúncios, análise, seguimento, SDK de terceiros ou pedidos de internet. Os dados ficam aqui, exceto um resumo mínimo enviado diretamente para o Apple Watch emparelhado.
