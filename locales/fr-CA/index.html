Fonctionnement de BattAI

Règles, sources et limites claires

BattAI utilise cinq valeurs fournies par les API publiques d’iOS : niveau de batterie, état de recharge, mode économie d’énergie, état thermique de l’appareil et heure. Les autres résultats sont calculés à partir de ces relevés ou ajoutés par vous. Chaque détail indique sa source et ses limites.

Importer des détails sur la batterie

Choisissez un fichier de diagnostic iOS. BattAI lit les champs de batterie pris en charge et indique leur source.

Exporter les données

Créez un fichier sur cet appareil. Rien n’est téléversé.
