Как работает BattAI

Понятные правила, источники и ограничения

BattAI использует пять значений из публичных API iOS: уровень заряда, состояние зарядки, режим энергосбережения, тепловое состояние всего устройства и время. Остальные результаты рассчитываются по этим показаниям или добавляются вами. У каждого показателя указаны источник и ограничения.

Импорт

Выберите диагностический файл iOS. BattAI считает поддерживаемые поля аккумулятора и укажет их источник.

Экспорт данных

Создайте файл на этом устройстве. Ничего не загружается.

Конфиденциальность

Без рекламы, аналитики, отслеживания, сторонних SDK и интернет-запросов. Данные остаются здесь, кроме минимального снимка, который отправляется напрямую на сопряжённые Apple Watch.
